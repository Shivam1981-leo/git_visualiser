# 🌳 Git Visualiser

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://git-visualiser.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

**Git Visualiser** is an interactive web-based tool designed to help developers, students, and beginners understand how Git works under the hood. By providing a real-time visual representation of repositories, branches, and commits, it demystifies complex version control workflows.

Check out the live demo: **[git-visualiser.vercel.app](https://git-visualiser.vercel.app/)**

## ✨ Features

- **Real-Time Visualization:** See branches diverge, commits stack up, and merges happen instantly as you type Git commands.
- **Interactive Sandbox:** Safely experiment with complex commands like `rebase`, `cherry-pick`, and `merge` without fear of breaking a real project.
- **Beginner Friendly:** Helps visual learners grasp abstract Git concepts through clear, intuitive node graphs.
- **Fast & Responsive:** Built for speed and works smoothly right in your browser.
